# Asimina Kafasi — Personal Website

A static personal website and portfolio.

## View locally

Open [`site/index.html`](site/index.html) in a browser. The page uses the local images and icons in [`site/assets/`](site/assets/).

## Publish with GitHub Pages

In the repository settings, enable GitHub Pages and select the `main` branch with the `/ (root)` folder, or publish the `site` folder using your preferred deployment workflow.

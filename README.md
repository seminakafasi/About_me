# Asimina Kafasi — Personal Website

A static personal website and portfolio.

## Live website

[Open Asimina Kafasi’s website](https://seminakafasi.github.io/About_me/)

## View locally

Open [`site/index.html`](site/index.html) in a browser. The page uses the local images and icons in [`site/assets/`](site/assets/).

## Publish with GitHub Pages

The `main` branch includes a GitHub Actions workflow that publishes the `site/` folder. In the repository settings, open **Pages** and set **Build and deployment → Source** to **GitHub Actions**. After that, pushes to `main` deploy the site automatically.
